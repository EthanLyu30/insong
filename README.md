## 已实现

- 温暖明亮的沉浸首页，保留五张卡片和中央手机的构图、透视及手写字体。顶部品牌和底部四栏导航始终可见，开场动态拼贴占主体区域的 3/4。按用户要求恢复原版彩色封面和选歌交互；点击卡片选择歌曲，中央手机打开歌曲入口，进入后及从其他模块返回“听见”仍显示原版卡片首页。共鸣通过独立导航进入。[还原实录](docs/hear-home-restored-20261001.png)
- 5 首各 48 秒的原创器乐样例，真实播放、进度拖动和片段标记。可选起止区间，播放到终点自动停止；没有区间时播放整首。每首歌绑定固定版本资源。
- 个人用户名与密码注册、登录、退出；数据库保存账号和记忆，密码使用加盐 PBKDF2 哈希。
- 记忆默认私密；一句话即可保存，播放位置、人生时间都可不填。创建支持请求去重，编辑、删除和补记有版本冲突检查。
- 左侧人生时间轴、宽幅图文卡、日期在正文上方；完整文字不截断，保留按歌曲筛选及同首歌的多次记录。年份由用户填写，未标年份单独显示。个人回忆搜索从页面移除，旧补记继续保留。
- 卡片支持选填标题、最多 8 个标签、最多 9 张照片，封面从所上传照片中选择；删除封面时顺延到剩余照片。详情按照片网格展示，支持大图、切换与 Escape 关闭；没有上传照片时使用歌曲配图。照片经校验、缩放与移除元数据后保存，只有本人或当前有效公开快照的读者可以访问。
- 3 个歌迷记录主题：散场以后、音乐节的夏天、跨城去见你；主题会从选歌一路带到记忆卡。推荐区连接已收录近期现场，排除取消日期，显示具体时间和状态；尚无热度数据，不声称热门排名。每个原创样例录音仍有 3 句示例词句，用于演示逐句定位。
- 卡片底部统一私密/公开入口，预览所选原文、标题、全部照片、标签、主题、场次及播放区间，再明确确认公开；支持匿名、是否分享人生时间及随时撤回。私人原文中未选的部分与补记不进入公共故事。修改标题、标签或照片也会撤回旧快照，等待再次确认；旧公开快照不会自动补入私人新增字段。
- 面向访客的“共鸣”页面：歌手、歌曲、活动、标签关键词搜索与可选经历匹配；两列照片卡突出歌名、歌手及故事标题。标签可直接点击，关键词搜索返回全部匹配，标签页二次搜索保留标签约束。翻面增加照片比例，完整公开原文可滚动阅读；详情使用用户提供的手写字体。普通歌曲页有大图、进度与播放控制，“音乐卡片”入口与听友共鸣入口并列；保留片段定位和重听。本次按文档要求不做波形选段。
- 第四个入口“足迹”：移动端整屏原生中国地图，47 个省会／主要城市可点选、拖动和缩放。全国使用自然航空影像、轻量晕渲、中国轮廓、暖金巡演光点和云层；放大时渐变为清晰的浅色矢量地图，显示道路、水系、公园、建筑和场馆。点击城市光点先靠近实际场馆地图位置，点击地图上的场馆标记才进入夕阳外景，再点击场馆进入夜场。目录收录邓紫棋、刘雨昕、凤凰传奇、时代少年团、洛天依、张杰、薛之谦共 7 位歌手／组合、84 条日期记录、16 个场馆，包含 3 条明确取消的记录。16 个场馆按各自建筑特点匹配外景和内景；封闭体育馆保留屋顶结构。夕阳与夜场删除加减按钮，继续支持拖动景深、双指缩放、滚轮和键盘。点歌曲或星星调用同一播放器；缺少音源明确提示。一键收藏、本人的到场印记按账号持久保存，记忆可关联具体日期，已取消场次不能新增到场。
- 公共经历匹配使用本地 E5；返回获准公开的原文候选，用户自行确认。模型缺失、忙碌或超时会明确降级到关键词。原有私人检索 API 保留兼容，当前个人记忆页面不再展示该功能。
- 服务端按账号限制列表、搜索、修改、删除；切换身份会清空当前页面数据。小林、阿远仍是**所有体验者可进入的共享样例账号**，请只输入虚构文字。

- 足迹日程分为“接下来 / 往期”，可按年月和“我关心”筛选；同一筛选贯穿全国地图、城市场馆及外景，保留选中的具体演出日期。每场显示核验日期，改期／取消说明保留。近景地图使用暖色建筑与光照、减少道路标签，接近时云层逐渐淡出；外景副标题和夜场日期有局部底衬，小屏提示避开下方日程。
- “关注歌手”和“我想去”由本人账号持久保存，“我关心”展示两者的并集；想去的城市／场馆有标记。往期、取消场次不能新标想去，已经保存的标记仍可取消。没有新接入通知推送或个人记忆联动。
- 收藏歌单保留原曲目、顺序、资料类型、核实日期及版本；资料更新时显示提示，由用户点“更新这张歌单”后替换。重复收藏和普通读取不会覆盖；冲突时重新读取本人已保存版本，须再次主动确认。旧收藏继续可读，明确标为曲目类型待核实，不继承目录中的新核实状态。

- 足迹歌曲星群按场次生成稳定的错落位置，星点大小和闪烁节奏有变化，保留歌名之间的间距；点击播放和展开歌单不会重新打乱位置。小屏可轻滑浏览剩余星点，系统减少动态效果时关闭闪烁。
- 本地资料维护工具可预览新增、改期、取消、场馆、歌单及音源变化，核对后按旧版本SHA写入并保留审核记录。旧ID不能删除；真实歌单必须有对应场次证据，音源需另附来源。尚未启用自动采集或AI提取，详见[资料维护](docs/footprints-data-maintenance.md)。

## 体验路径

1. 首页点击音乐卡片进入故事，或点空白／按钮进入推荐页；从故事、歌曲或主题进入记录。
2. 写下经历，可选标题、标签、照片和封面、年份、人生阶段、词句与播放区间，默认私密保存。“试听配乐 / 选一句词”可展开。
3. 在“我的记忆”左侧时间轴找回卡片；打开详情，看完整原文与照片，用心情、照片或一句话补记。
4. 在卡片底部点“仅自己可见”→“公开”，检查公开预览和连续原文片段；按需修改署名与时间，点击“确认公开这张卡”。只打开预览不会发布。
5. 进入“共鸣”，输入相近经历，翻卡看公开原文并播放。若选了 00:10–00:14，播放会在 00:14 停止；未选区间则播放整首。
6. 在“足迹”搜索歌手或城市，点击城市光点或近期行程的“靠近这场现场”，先停在场馆周围的真实地图；再点击带场馆名称的标记，进入该场馆的夕阳外景。拖动调整景深视角，双指在图像清晰范围内缩放；没有加减或复位按钮。点击场馆或“走进这一晚”，推进并过渡到对应夜场。可展开“全部场次”选择日期，取消记录保留说明但不能入场或新增到场。点星星或曲目列表选歌，“收藏为歌单”可保存到“我的现场歌单”；往期场次可在“同场记录”标记到场。通过“记下这一晚”记录，公开后在按需打开的同场故事里出现。夜场会区分已确认歌单和关联作品，目前目录中的现场歌单均尚未确认。
7. 回到原账号将卡片改回私密。公共直链、新搜索与照片公共访问失效，原文仍在个人空间；编辑原卡也会撤回旧版，等待再次确认。删除同时移除私人卡和公开片段。

## 本地启动（Windows PowerShell）

```powershell
cd backend
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另开终端：

```powershell
cd frontend
npm install
npm run dev -- --host 127.0.0.1
```

仓库维护 `pnpm-lock.yaml`，也可用 `pnpm install --frozen-lockfile`、`pnpm dev --host 127.0.0.1` 启动。原生 MapLibre 使用 Esri World Imagery 卫星影像，叠加 Mapterhorn 地形阴影和 OpenFreeMap / OpenStreetMap 矢量道路，无需地图密钥；网络不可用时底图不能正常呈现，署名可在地图信息按钮中查看。三维场景需要 WebGL 2，不支持时保留城市、日程与歌单操作。

打开 `http://localhost:5173`。Vite 代理 `/api` 到本机后端；同源访问保留会话 Cookie。当前会话有效期为 24 小时，过期后重新登录。SQLite 位于 `backend/data/demo.db`；启动会增量补齐旧表字段，不重置已有内容。请保留该目录。

macOS/Linux 用 `python3` 创建环境，然后使用 `.venv/bin/python`、`.venv/bin/hf`，其余命令相同。

### 启用本地经历匹配

首次安装后，在 `backend` 目录下载固定版本的公开模型：

```powershell
.venv/Scripts/hf.exe download Xenova/multilingual-e5-small onnx/model_quantized.onnx tokenizer.json config.json tokenizer_config.json --revision 761b726dd34fb83930e26aab4e9ac3899aa1fa78 --local-dir models/multilingual-e5-small
```

模型文件不入 Git；在本机保留供推理使用。下载连接 Hugging Face，**检索时的私人文字和查询只在应用后端本机处理，不发送给模型服务商**。`GET /api/search/status` 返回模型文件是否就绪。模型的 [ONNX 版本](https://huggingface.co/Xenova/multilingual-e5-small) 源自 [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small)。

语义检索有 5 秒等待上限，同时只运行一个模型任务；忙碌、缺文件、初始化或推理失败时走关键词。个人搜索仅使用当前账号记录；公共搜索仅使用已发布快照中的原文片段、获准分享的人生阶段和歌名。无私人正文向量文件或跨用户正文缓存。长文分段编码；返回前重新检查权限、发布状态及版本，避免推理期间撤回后返回旧内容。

相似度阈值 0.865 是小样例试验后的初值，不是“86.5% 置信度”；仍会漏找或误匹配。例如“现场结束了还不想回家”可能同时找到演唱会和毕业晚会，必须由用户确认。尚未完成 PRD 中的 50 条独立评测和真实用户对照，不能据此声称 AI 优于普通检索。

## 资源与产品边界

- 5 首音频是本项目生成的原创器乐练习，来源与版本见 [media/README](backend/media/README.md)；这些录音名称与逐句定位文本为原创演示素材，没有人声演唱。另增周杰伦《稻香》、邓紫棋《光年之外》《泡沫》、刘雨昕《REALITY》、五月天《倔强》的真实歌曲元数据，配以明确标注的虚构故事与场景插画。这些歌的音源尚未接入，界面明确提示不可播放，不用原创器乐代替歌手录音。没有真实 QQ 音乐曲库、歌词、平台账号或播放器接入。
- 旧公开种子卡一次性迁移为公开片段，原始记忆接口改为本人可读；原本私密的卡不会迁移到公开。撤回后重启服务不会再次公开。共享样例账号内的操作仍由所有体验者共享，个人真实记录请使用个人账号。
- 个人账号是独立站点账号，暂无密码找回、端到端加密或生产托管。部署前应补齐 HTTPS、域名/Origin 配置、账号恢复、备份、滥用防护及完整授权资源接入。本地服务默认绑定回环地址。
- 人生时间轴按用户填的年份降序排列，同年按记录创建时间排列；未填年份另列。保留“去年夏天”等用户原话，不推断准确日期。
- 足迹是截至 2026-10-01 核对的部分场次目录，并非全国实时演出数据。84 条记录含历史场次及 3 条取消记录，81 条未标取消不等于全部实际举行。16 个场馆有带来源的 WGS84 坐标，部分为公共建筑轮廓中心，不代表出入口测绘精度或导航终点。地图使用 Esri 卫星影像、DataV GeoAtlas 省界、OpenStreetMap 街道和 Mapterhorn 地形阴影。每个场馆独立匹配一对建筑参考概念图，共 32 张；保留深圳大运体育场原版 853×1844 图，新增 30 张原生约 941×1672 图，没有插值放大。构图参考建筑特点，舞台、灯海和周边景观有演绎。Three.js 景深网格拖动限于左右12°、上下7°，按源像素与视口限制放大；这是受限景深视角，不是实拍、测绘模型或360°漫游。未知场馆不套用别的城市图片。宽屏极限角度仍有覆盖画布的采样限制；公告不等于实际举行，到场由用户手动标记。
- 星空和收藏目前使用目录内的歌手关联作品，尚未核实实际演出曲目；资料类别与原始出处留在目录和来源文档，界面按用户要求只列曲目。不可在投稿中宣称这些是已确认的完整现场歌单。收藏是本项目账号内的曲目快照，不会同步创建 QQ 音乐歌单；目录资料更新不会悄悄覆盖，用户选择更新时会核对收藏版与目录版，替换为最新已审核资料。用户确认暂无比赛 QQ 音乐播放接口或歌手音频文件，因此现有歌手曲目显示“暂缺音源”。播放器已用项目原创音源实测真实播放；没有把原创器乐伪装成歌手录音。接入时为目录中相应曲目提供 `audio_url` 和可选 `audio_label`，支持本站 `/api/audio/…` 或可直接播放的 HTTP(S) 音频地址；QQ 搜索网页不是音频地址。完整第三方曲库与账号授权仍需另行接入。
- 照片支持 JPEG、PNG、WebP，单张不超过 5 MiB；数据库内存储最长边不超过 2048px 的净化 JPEG。公开卡撤回后照片立即失去公共访问资格；删除记忆不自动清除未再引用的照片，当前没有用户照片库或孤立照片自动回收功能。
- QQ 音乐实测与自发回访研究尚未完成，不宣称平台首创或已经验证长期需求。
