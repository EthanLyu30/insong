# 歌里有我

一个可以操作的音乐记忆 H5：**主题或歌曲 → 一句词/音乐时点 × 人生年份/阶段 → 私密保存 → 时间轴回看 → 自愿公开原文片段 → 按经历发现共鸣 → 重听对应片段**。

## 已实现

- 温暖明亮的沉浸首页，保留五张卡片和中央手机的构图、透视及手写字体；首屏只显示动态拼贴，点击卡片外空白进入文案并显示导航。
- 5 首各 48 秒的原创器乐样例，真实播放、进度拖动和片段标记。可选起止区间，播放到终点自动停止；没有区间时播放整首。每首歌绑定固定版本资源。
- 个人用户名与密码注册、登录、退出；数据库保存账号和记忆，密码使用加盐 PBKDF2 哈希。
- 记忆默认私密；一句话即可保存，播放位置、人生时间都可不填。创建支持请求去重，编辑、删除和补记有版本冲突检查。
- 中央人生时间轴、左右交错图文卡、按歌曲筛选及同首歌的多次记录。年份由用户填写，未标年份单独显示；“随手留一刻”支持心情贴纸、照片与一句话，旧补记继续保留。
- 上传自己的照片作为记忆封面，保留歌名、歌手。照片经服务端校验、缩放与移除元数据后保存，只有本人或当前有效公开快照的读者可以访问。
- 3 个记录主题：散场以后、毕业那年、第一次远行；主题会从选歌一路带到记忆卡。每个样例录音有 3 句原创示例词句，用于演示逐句定位。
- 卡片底部统一私密/公开入口，预览文字、照片、主题、场次及播放区间，再明确确认公开；支持匿名、是否分享人生时间及随时撤回。私人原文中未选的部分与补记不进入公共故事。
- 面向访客的“共鸣”页面：吸顶搜索、顶部主题、两列错落双面卡。翻面阅读作者公开的完整原文并尝试播放，保留手动播放入口；支持原文检索、公共直链和同一句词下的不同经历。
- 第四个入口“足迹”：移动端整屏原生中国地图，47 个省会／主要城市可点选、拖动和缩放。全国使用自然地形，城市显示道路、水系、公园和场馆，近景渐入卫星影像。搜索邓紫棋、刘雨昕、凤凰传奇、时代少年团、洛天依，区分往期与待演；目录收录 40 个有来源场次。地图、三维场馆和星光现场共用 MapLibre 画布与相机，连续拉近、环绕、进入夜场；支持拖动、双指缩放、滚轮和键盘。点星星选曲目，直接显示曲目列表，一键收藏为个人现场歌单。本人到场印记和收藏按账号持久保存，记忆仍可关联具体日期。
- 本人记忆关键词查找和本地 E5 语义检索；返回原文候选，用户自行确认。模型缺失、忙碌或超时会明确降级到关键词。
- 服务端按账号限制列表、搜索、修改、删除；切换身份会清空当前页面数据。小林、阿远仍是**所有体验者可进入的共享样例账号**，请只输入虚构文字。

[双坐标音乐记忆 v3](docs/双坐标音乐记忆_v3.md) 保留产品主轴；本次交互和页面以用户提供的《9.29修改建议.docx》、[9.29 改版说明](docs/2026-09-29-product-redesign.md)及本 README 为准。[PRD v2](docs/歌里有我_PRD_v2_差异化方案.md) 保留为历史方案。演出资料的证据范围见[足迹来源](docs/footprints-sources.md)。

## 体验路径

1. 首页点击卡片外空白进入文案；从首页选歌，或进入“共鸣”选择主题。
2. 写下经历，可选照片、年份、人生阶段、词句与播放区间，默认私密保存。“试听配乐 / 选一句词”可展开。
3. 在“我的记忆”中央时间轴找回卡片；打开详情，用心情、照片或一句话补记，也可搜索自己的经历。
4. 在卡片底部点“仅自己可见”→“公开”，检查公开预览和连续原文片段；按需修改署名与时间，点击“确认公开这张卡”。只打开预览不会发布。
5. 进入“共鸣”，输入相近经历，翻卡看公开原文并播放。若选了 00:10–00:14，播放会在 00:14 停止；未选区间则播放整首。
6. 在“足迹”搜索歌手或城市，点击城市 → 场馆，或从近期行程点“靠近这场现场”；原生地图相机飞向场馆，露出与地图地理位置对齐的三维建筑。拖动可环绕、双指或按钮可缩放，“重新运镜”恢复取景。再点击场馆或“走进这一晚”时，镜头靠近、逐渐打开广角并点亮夜场全景；夜场仍可拖动环视。可展开“全部场次”选择日期。点星星或曲目列表选歌，点“收藏为歌单”，可在“我的现场歌单”找回；往期场次可在“同场记录”标记到场。通过“记下这一晚”记录，公开后在按需打开的同场故事里出现。
7. 回到原账号将卡片改回私密。公共直链、新搜索与照片公共访问失效，原文仍在个人空间；编辑原卡也会撤回旧版，等待再次确认。删除同时移除私人卡和公开片段。

## 本地启动（Windows PowerShell）

```powershell
cd backend
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另开终端：

```powershell
cd frontend
npm install
npm run dev -- --host 127.0.0.1
```

仓库维护 `pnpm-lock.yaml`，也可用 `pnpm install --frozen-lockfile`、`pnpm dev --host 127.0.0.1` 启动。原生 MapLibre 使用 OpenFreeMap / OpenStreetMap 矢量底图、Natural Earth 地形和近景 Esri 影像，无需地图密钥；网络不可用时底图不能正常呈现，署名可在地图信息按钮中查看。三维场景需要 WebGL 2，不支持时保留城市、日程与歌单操作。

打开 `http://localhost:5173`。Vite 代理 `/api` 到本机后端；同源访问保留会话 Cookie。当前会话有效期为 24 小时，过期后重新登录。SQLite 位于 `backend/data/demo.db`；启动会增量补齐旧表字段，不重置已有内容。请保留该目录。

macOS/Linux 用 `python3` 创建环境，然后使用 `.venv/bin/python`、`.venv/bin/hf`，其余命令相同。

### 启用本地经历匹配

首次安装后，在 `backend` 目录下载固定版本的公开模型：

```powershell
.venv/Scripts/hf.exe download Xenova/multilingual-e5-small onnx/model_quantized.onnx tokenizer.json config.json tokenizer_config.json --revision 761b726dd34fb83930e26aab4e9ac3899aa1fa78 --local-dir models/multilingual-e5-small
```

模型文件不入 Git；在本机保留供推理使用。下载连接 Hugging Face，**检索时的私人文字和查询只在应用后端本机处理，不发送给模型服务商**。`GET /api/search/status` 返回模型文件是否就绪。模型的 [ONNX 版本](https://huggingface.co/Xenova/multilingual-e5-small) 源自 [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small)。

语义检索有 5 秒等待上限，同时只运行一个模型任务；忙碌、缺文件、初始化或推理失败时走关键词。个人搜索仅使用当前账号记录；公共搜索仅使用已发布快照中的原文片段、获准分享的人生阶段和歌名。无私人正文向量文件或跨用户正文缓存。长文分段编码；返回前重新检查权限、发布状态及版本，避免推理期间撤回后返回旧内容。

相似度阈值 0.865 是小样例试验后的初值，不是“86.5% 置信度”；仍会漏找或误匹配。例如“现场结束了还不想回家”可能同时找到演唱会和毕业晚会，必须由用户确认。尚未完成 PRD 中的 50 条独立评测和真实用户对照，不能据此声称 AI 优于普通检索。

## 资源与产品边界

- 音频是本项目生成的原创器乐练习，来源与版本见 [media/README](backend/media/README.md)。歌曲名称与逐句定位文本为原创演示素材。示例词句配合器乐展示位置关系，没有人声演唱；没有真实 QQ 音乐曲库、歌词、平台账号或播放器接入。
- 旧公开种子卡一次性迁移为公开片段，原始记忆接口改为本人可读；原本私密的卡不会迁移到公开。撤回后重启服务不会再次公开。共享样例账号内的操作仍由所有体验者共享，个人真实记录请使用个人账号。
- 个人账号是独立站点账号，暂无密码找回、端到端加密或生产托管。部署前应补齐 HTTPS、域名/Origin 配置、账号恢复、备份、滥用防护及完整授权资源接入。本地服务默认绑定回环地址。
- 人生时间轴按用户填的年份降序排列，同年按记录创建时间排列；未填年份另列。保留“去年夏天”等用户原话，不推断准确日期。
- 足迹是截至 2026-09-30 核对的部分场次目录，并非全国实时演出数据。全国图使用 Natural Earth 自然地形及 DataV GeoAtlas 省级轮廓；城市道路来自 OpenStreetMap，近景影像来自 Esri。9 个场馆以公共地理编码匹配到位置，4 个未确认匹配的场馆保持城市精度，不伪造精确定位。外景为原创的通用三维建筑，内景为生成的球面概念全景；可环绕，但不是该场馆的真实照片、测绘模型或导航。未知坐标场次仍可查看明确标记的概念全景。歌单星星是交互入口，不代表现场星体位置。公告不等于实际举行，到场由用户手动标记。
- 星空和收藏目前使用目录内的歌手关联作品，尚未核实实际演出曲目；资料类别与原始出处留在目录和来源文档，界面按用户要求只列曲目。不可在投稿中宣称这些是已确认的完整现场歌单。收藏是本项目账号内的曲目快照，不会同步创建 QQ 音乐歌单；暂无授权曲目音源。
- 照片支持 JPEG、PNG、WebP，单张不超过 5 MiB；数据库内存储最长边不超过 2048px 的净化 JPEG。公开卡撤回后照片立即失去公共访问资格；删除记忆不自动清除未再引用的照片，当前没有用户照片库或孤立照片自动回收功能。
- QQ 音乐实测与自发回访研究尚未完成，不宣称平台首创或已经验证长期需求。

## 验证

```powershell
cd backend
.venv/Scripts/python.exe -m pytest -q
# 另一个终端，在 frontend：
npm test
npm run build
```

后端覆盖：旧库升级、注册与会话、账号隔离、请求去重、冲突反馈、编辑/补记/删除、关键词与语义降级、原文依据、无结果、音频 Range 请求、公开字段隔离、明确发布、撤回/删除/编辑失效、推理中撤回，以及词句/录音匹配与主题/年份校验。新增照片上传限制、净化和访问控制、区间校验、丰富补记、事件关联及足迹归属。删除后保留不含正文的请求回执，避免编号复用和重试复活已删除内容。前端覆盖时间输入、人生年份分组、登录返回地址、API 错误处理、访客共鸣、公开预览与同意、首屏几何保持、翻卡区间播放、足迹保存与身份切换，以及关闭上传后可继续保存补记。

检索结果始终保留作者原文及关键词入口；功能检查与模型候选不代表真实用户价值实验。部署为公共服务前仍需补齐内容举报/处理、滥用防护及资源授权等运营能力。
