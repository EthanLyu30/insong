# 9.29 产品改版实施说明

依据：用户提供的《9.29修改建议.docx》及本轮确认的歌手「邓紫棋、刘雨昕」。保持双坐标音乐记忆、默认私密和公开快照机制，落实页面与记录体验重构。

## 体验与验收

- 听见：初始只有铺满视口的动态拼贴，原有五卡和手机的投影几何不变；点击卡片外空白或键盘按钮进入文案，平滑转场后显示导航。尊重减少动态效果设置。
- 共鸣：搜索吸附顶部，主题入口前移；两列错落竖卡，封面占正面约一半，翻面显示公开完整原文、照片和播放器。一次只播放一首；翻面尝试播放，浏览器拦截时可手动播放。设置区间时只播放该区间，否则从头播放整首；歌词位置仍可单独重听。
- 我的记忆：中央时间轴、左右交错；每张摘要卡约三分之一图片、三分之二文字，点击展开详情。按人生年份分组，未标年份独立分组。
- 记录：照片作为个人卡、公开卡封面及背面照片，保留歌名和歌手；可填写起止时间；私密/公开集中在卡片底部。公开必须主动确认选中的文字与照片，私密原文和后来补记不能混入公开结果。
- 随手留一刻：心情贴纸、照片、一句话，至少一个非空；继续保留原始记忆。旧补记不丢失。
- 足迹：第四个同级入口，先选歌手，再看示意地图中的真实场馆/有来源的场次；区分演出发生与本人到场，个人点亮持久保存；关联公开故事、歌曲与记录入口。无核实榜单时不生成名次；真实歌曲无授权音源时提供外部入口，不拿样例音频冒充。

## 接口约定

Memory / PublicStory 增加 `photo_id`, `photo_url`, `end_ms`, `event_id`（可空）；照片公开范围由有效 PublicStory 快照决定。POST /api/photos 使用 `{data: base64}`，返回 `{id,url}`；服务端限制体积、校验图片、移除元数据，照片不挂静态公开目录。GET /api/photos/{id} 对所有者或有效公开引用放行。

创建/修改记忆可传上述 id、end_ms；end_ms 非空必须同时有 offset_ms 且 `0 <= offset_ms < end_ms <= duration_ms`。反思接口扩展 `{revision,text?,mood?,photo_id?}`，至少一项非空。公开快照保存照片、播放区间和场次；编辑原始卡后仍原子撤回旧公开快照。

GET /api/footprints/catalog 返回歌手、场次、来源与歌曲的目录；GET /api/footprints 返回当前用户点亮的 event_id 数组；PUT /api/footprints/{event_id} 接受 `{attended:boolean}` 并幂等保存。Memory 及 /api/stories 支持 event_id 关联/筛选。目录 JSON 由足迹模块提供，后端验证合法 id。

## 实施顺序

1. 已检查远端 main 无更新，继续本地 main。前端、后端、足迹使用独立文件范围并行实现。
2. 后端先验证图片访问边界、区间、补记和点亮归属，兼容现有数据库。
3. 前端落实首屏转场、双面卡、时间轴与记录表单，连接接口。
4. 联调真实保存/刷新/公开/撤回、照片访问与区间播放；检查桌面和移动端布局。
5. 全量已有测试、必要新增测试与构建；一次独立整体审查，修复实质问题。
6. 更新交付说明，仅推送 main:lxy；清理可安全清理的临时输出。

## 完成与验证记录（2026-09-29）

- 全量后端：51 项通过。全量前端：15 项通过。TypeScript 检查及 Vite 生产构建通过。后端仅有现有 Starlette/httpx 测试客户端弃用提示，无失败。
- 浏览器：初始首页没有顶部/底部导航，无需滚动；点击空白进入文案。自动化验证卡片投影矩阵在进入前后不变。
- 390px 手机宽度：共鸣页无横向溢出，滚动后搜索固定在视口顶部；个人时间轴交错呈现；足迹地图、场次、入口可操作。验收结束恢复默认视口。
- 实际上传一张项目原创图片，用虚构经历保存 00:10–00:14 区间，添加心情与一句话，主动公开后在对应演出下看到照片和原文；实际播放在 00:14 停止。公开页不包含私密补记和未同意的人生时间。
- 到场标记实际点亮、刷新保持，再取消恢复原状态。数据按账号保存，切换歌手不会误带前一歌手的请求结果。
- 独立整体审查发现的两项问题已修复，并分别通过失败→修复→通过的回归验证：关闭正在上传照片的补记后保存按钮恢复；公开预览展示关联主题，防止用户不知道主题也将公开。
- 已撤回并删除本次虚构验收卡与其未再被引用的照片，公开故事和照片地址均返回 404。原有用户记录及种子内容保留。

## 交付范围

首批足迹包含邓紫棋 4 场、刘雨昕 2 场历史资料；公告和演后记录明确区分，来源见 `footprints-sources.md`。关联作品与 QQ 音乐官方榜单提供外部入口，站内仍使用原有原创演示音频。真实授权曲库、实时演出/榜单接口尚未接入；也不将到场印记解释为已核验购票或本人行程。

照片读取随公开快照的有效性即时校验。当前没有孤立照片自动回收；未再引用的照片仍由原上传者私有持有，详见 README。旧数据库使用增量迁移，未重置数据。
