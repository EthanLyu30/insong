## 曲目与 QQ 音乐

每场目录支持 `setlist_kind: confirmed / partial / artist_collection`。目前全部为 `artist_collection`，代表歌手关联作品，未核实这些作品是否在本场演出，也没有已核实的完整本场歌单。夜空和资料面板均明确提示，不能在参赛演示中将其说成现场实际歌单。未来有可核实场次歌单时，应记录来源并改为 `confirmed` 或 `partial`。

每个星星连接 `https://y.qq.com/n/ryqq_v2/search?w=歌手 歌名`；找歌单入口同样进入 QQ 音乐搜索，没有直接创建平台歌单，也没有 Apple Music、酷狗或代理音视频。验证中 QQ 音乐页签返回官方搜索页标题，但该外站页面在当前内嵌浏览器读取超时，未据此声称可完成外站试听。

## 地图与场馆

- [DataV GeoAtlas](https://geo.datav.aliyun.com/) 的[全国省级 GeoJSON](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)作为地图底图，保留原省级轮廓、台湾、香港、澳门及南海诸岛。资源本地打包，地图加载不依赖第三方在线地图。
- 城市经纬度为城市中心的近似点位，以 Mercator 投影到 SVG，包含省会／首府及主要演出城市；点击城市展示目录内场馆。城市点位不是场馆地址。
- 场馆近景及夜景为项目原创 SVG 艺术化建筑，不是该场馆实景或卫星照片，也不承诺真实建筑外形。底图与场馆视图做缩放、淡入与星光动画；支持减少动画偏好。
- “往期”仅由北京时间下的日期判定；本人是否到过依赖账号下手动保存的到场记录。

## 接口与兼容

- `GET /api/footprints/catalog`：公开目录，含 `cities`、艺人、场次、来源、`verified_on` 和服务端北京时间 `today`。
- `GET /api/footprints`：当前账号的 `event_id[]`。
- `PUT /api/footprints/{event_id}`：`{attended: boolean}`；成功返回本人完整 `event_id[]`。未来日期不可标记到场。
- `GET /api/stories?event_id=...`：只显示这个日期的已公开快照。
- 保留原有六个 `event_id` 和记忆关联。`/footprints?event=...` 直接进入对应夜空；`/?event=...` 保留记录入口，登录返回链接保留艺人、城市、场馆和日期。

读取失败时阻止误写；保存不做乐观更新，失败保留原状态。卸载或切换账号终止旧请求并忽略迟到结果。前端验证全国复位、空城市、日期切景、QQ 域名、未来到场禁用、重复点击和旧响应；后端覆盖归属与北京时间跨日。
