# 歌里有我 · 双坐标音乐记忆 v3

本轮按用户确认的原方案重做：歌曲时刻 × 人生时刻。私人记录与公开共鸣共同构成产品主路径。

## 可操作的主路径

1. 从歌曲或主题进入，选择一句词或播放位置，写下经历与人生年份/阶段。
2. 默认私密保存；在“我的记忆”按人生年份回看，同一首歌可记录多次。
3. 主动挑选原文片段，预览公开卡，选择是否分享人生时间、是否匿名，明确确认公开。
4. “共鸣”面向访客开放：按一句经历搜索已公开的原文，显示匹配依据、歌曲与音乐位置。
5. 进入故事重听对应片段，看同一句词下其他人的经历，或为自己留下新的一张卡。
6. 随时撤回公开；私人原文和今天的补充继续保留。修改原文/坐标会撤回旧的公开版本，需重新确认。

## 产品边界

- 原有温暖明亮首页、五张卡片与中央手机的几何布局不变。
- 人生年份由用户填写；不从模糊描述猜测年份。未填年份独立展示，不冒充发生日期。
- 公开的是用户选择的原文片段。个人完整原文、补充、未同意分享的人生时间不进入公共检索。
- AI负责相似经历检索，展示原文依据；没有相关结果时明确说明。模型不可用时标注关键词降级。
- 当前是独立 H5 验证。使用原创器乐与明确标记的原创示例词句展示定位，尚未接入 QQ 音乐歌曲、歌词、账户或播放能力。
- QQ 音乐 COACH 截图已证明“歌曲＋故事投稿”。本项目不以此单点声称独创；默认私密、可回看、逐句/时间定位、授权后按经历发现的组合增量仍需实测竞品。
- 样例故事明确标记，不能当作真实用户验证。比赛结果、用户留存与检索质量不作未验证承诺。

## 本轮验收

- 私密创建、人生年份分组、同歌多卡、主题传递、词句/时点定位可操作。
- 公开预览与明确确认；他人只能看获准公开字段，私人原始接口仅本人可读。
- 公开后可被检索，点击查看原文、重听位置；撤回/删除/修改后公共列表、直链、检索立即失效。
- 检索进行中发生撤回，也不返回旧的公开内容。
- 登录切换及离页后的异步请求不覆盖新页面。

## 实现顺序

1. 后端公开快照、迁移、坐标/主题验证，先写隔离与撤回测试。
2. 共鸣与公开详情页、主题入口、时间轴、发布预览及词句交互。
3. 单元/集成测试、构建、浏览器实测闭环，独立复核并修复。
4. 更新使用说明；检查远端 main；本地 main 提交，仅推送远端 lxy。
