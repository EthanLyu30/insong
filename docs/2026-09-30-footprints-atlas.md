# 足迹：全国地图、场馆近景与演唱会星空

依据用户 2026-09-30 的明确实施要求，本轮在本地 main 完成，检查并先同步 origin/main，最后推送 main:lxy。初始基线 1187217 为上一版 PR 的合并提交。

## 设计

以全国地理底图为移动端 100dvh 主舞台，保留省级轮廓、台湾和南海诸岛，使用轻柔纸感、低饱和海水、立体场馆表现。省会与主要演出城市均可进入；未核实日程留空。有日程的城市点亮。

歌手搜索置于地图上方浮层，选中后只点亮其场次，按北京时间区分往期、今日、待演；展示近期行程简洁浮层。地图支持拖动、双指缩放、按钮缩放、全国复位。

点击城市进入该地场馆；点击场馆从全国拉近到带公园、步道和场馆建筑的近景，底部显示该场馆最近场次。点击场次切换夜空，场馆变为夜景，曲目成为可点选的星星；选中星星显示歌名与 QQ 音乐入口。返回场馆、返回全国保留歌手筛选。键盘也能依次操作城市、场馆、场次、星星。

去除原页面长标题、独立歌手卡、重复说明、整块作品列表、单独大票根与默认展开故事墙。只保留紧凑的场次详情、手动到场印记、记忆入口、按需展开的该场故事和资料来源。

## 数据约束

保留已有 event_id，兼容原卡关联及到场状态。全国地理底图使用阿里云 DataV GeoAtlas 省级 GeoJSON。城市位置按经纬度投影；场馆为艺术化近景，无地理导航承诺。

目录是有来源的部分演出资料，包含官方公告、艺人工作室和售票方官宣。待演场次依据公布日期，不由巡演规律推断。歌单标记 `setlist_kind`，未经核实的关联作品不能称本场真实完整歌单。所有音乐入口仅使用 y.qq.com；官方未提供可核实歌单链接时采用 QQ 音乐搜索入口并明确标注。用户收藏／到场、平台曲库和真实行程各自保留现有权限边界。
