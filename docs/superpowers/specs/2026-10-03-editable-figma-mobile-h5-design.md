# 「歌里有我」手机 H5 可编辑 Figma 设计规范

日期：2026-10-03
状态：方案已获用户确认，待 Figma 连接后执行
页面基线：当前仓库 `main`，提交 `29e35a1`，以该版本实际运行的手机 H5 为视觉与交互依据。

## 目标与交付

新建一份 Figma Design 文件，忠实重建现有手机 H5 的完整页面及关键状态，供用户自行做后续视觉调整。页面中的文字、图标、按钮、卡片、输入框、导航、弹层及各区域的位置和大小均可在 Figma 中直接编辑；不得将整页截图当作最终页面。照片、地图底图、场馆画面等图片的内部像素无需拆分，但图片本身必须是可替换、可裁切、可移动、可缩放的独立图层。

交付包括：Figma 文件链接、页面／状态覆盖清单、原型跳转说明、未能忠实复刻之处的例外清单。此任务仅覆盖手机 H5，不制作桌面端设计稿，也不要求 Figma 原型实际连接后端、播放音频或持久保存数据。

## 文件结构与编辑规则

文件分区：`00 流程总览`、`01 样式与组件`、`02 听见与共鸣`、`03 记录与我的记忆`、`04 足迹与歌单`、`05 帐号、弹层与系统状态`。流程总览显示页面树、关键分支及相应原型入口；每个主要场景保留独立、清晰命名的手机画板。默认以 390 px 宽手机视口重建，长页面按真实滚动内容呈现，并检查 360 px 宽时主要组件不溢出。

重复元素建立主组件与实例：顶部栏、五项底部导航、歌曲卡片、记忆卡片、故事卡片、按钮、输入框、标签、空状态、确认弹层等。文字保留为原生文本；图标保留为矢量或可编辑形状；组件实例支持替换文案、图片与状态。只在组件内部有明确排列关系时使用 Auto Layout，不以锁定约束妨碍用户调整页面级组件的位置与尺寸。图层、变体和交互触点使用可读名称，不留整页扁平化图层。

## 页面与状态覆盖

以 `frontend/src/App.tsx` 的实际路由为页面基准，不凭空扩展产品功能：

| 区域 | 页面及需呈现的主要状态 |
| --- | --- |
| 听见 | 首页 `/` 的开场／五卡片体验；带 `theme`、`event`、`choose` 参数时的选歌入口；歌曲详情 `/songs/:songId` 的故事与“我的”内容、试听状态。 |
| 共鸣 | `/discover` 默认、搜索结果、无结果及语义回退；故事详情 `/stories/:storyId`；主题详情 `/themes/:themeId`。 |
| 记录 | 底部“记录”入口 `/create`；歌曲写记忆 `/songs/:songId/write`，包括私密默认、公开选项、选取照片、补充细节、必填校验及提交反馈。 |
| 我的记忆 | `/memories` 的时间线／卡片视图、筛选及空状态；`/memories/:memoryId` 的私密／公开详情、发布预览或撤回、照片灯箱、删除确认、快捷补记；`/memories/:memoryId/edit` 的编辑状态。 |
| 足迹与歌单 | `/footprints` 的全国地图、选中城市／场馆、场馆外景、夜空场景、搜索筛选、信息面板展开／收起、同场故事及现场歌单入口；`/playlists` 的列表、详情、空状态及版本冲突提示。 |
| 帐号与通用 | `/account` 的访客、注册／登录和示例帐号切换；访客访问受限内容时的引导；加载、失败／重试、空状态、404 和返回路径。 |

不是每个数据排列都要重复制作画板，但每种会改变布局、控件或去向的关键状态都要有可检查的画板或组件变体。图库、地图等媒体可以使用图片图层；其覆盖的文本、按钮、标记、抽屉和热点需独立保留。

## 原型逻辑

建立可点击的核心路径：五项底部导航；首页选歌 → 歌曲详情／写记忆 → 记忆详情；共鸣 → 故事／主题 → 歌曲／记录；我的记忆 → 详情 → 编辑、公开／撤回或删除确认；足迹全国地图 → 城市／场馆 → 外景／夜空 → 同场故事／歌单。帐号保护路径需从触发位置到帐号页，并在原型中演示完成登录后回到原目标。返回按钮按当前 H5 的“优先返回应用内上一页，否则用兜底页”规则标注代表性流转。

Figma 只模拟代表性数据与操作结果；依赖帐号、权限、后端、真实地图、音频播放、上传及保存的行为，以独立状态画板或旁注写明触发条件，不伪称原型具有真实运行能力。所有可见的主要操作控件均应有目标画板、状态切换或明确旁注，不留下无法理解的死按钮。页面跳转须与当前 H5 路由一致，特殊查询参数入口须保留上下文。

## 制作与验收

1. 连接 Figma 插件后，检查可用的文件创建、节点编辑与原型连接能力；若能力不足以交付原生可编辑文件，先说明限制并征得用户选择，不以整页截图冒充完成。
2. 在固定手机视口逐页对照当前运行的 H5，采集视觉样式、文案、素材与状态；先做组件库，再完成页面与状态画板，最后连原型。
3. 对每个页面检查：视觉接近当前 H5；标题、按钮、卡片、输入等可单独选取和移动；图片可替换；滚动内容与遮罩层级正确；主要点击和返回路径可走通。
4. 提交文件链接及覆盖表，列出实际无法复刻或尚未接线的项。用户可直接在该文件中修改组件位置和视觉。

本规范不修改产品代码。Figma 帐号连接由用户本人在插件安装／授权界面完成，无需提供密码或个人访问令牌。
