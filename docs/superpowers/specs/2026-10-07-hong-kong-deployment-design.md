# 香港服务器迁移设计

日期：2026-10-07

## 目标与约束

用户已购买腾讯云香港轻量服务器和 50GB 优选流量包，并授权操作与项目迁移。目标是缩短国内手机首次访问和接口等待，继续使用 `insong.me`，保留源仓库 `Saskia-1/TME:lxy` → 部署仓库 `EthanLyu30/insong:main` 的同步顺序和自动发布。

已核对实例为 Ubuntu 24.04、x86_64、2核4GB、70GB SSD、30Mbps 峰值带宽；优选加速已开启。服务器仅购买一个月，数据与备份需在到期前导出或续费。使用已经购买的资源。

## 方案选择

采用同机全栈部署：Nginx 提供前端和 HTTPS，FastAPI 提供同源 `/api`，PostgreSQL 保存账号、记录、收藏、会话和照片，量化 E5 继续在后端常驻运行。

相比仅迁后端，同机部署同时消除原免费后端休眠与跨地区数据库往返。仅迁前后端并保留 Mumbai 数据库可作为数据迁移受阻时的临时过渡，不能当作已经完成本方案。

Cloudflare 负责域名注册和 DNS；正式访问优先直连腾讯香港优选线路。用实际关闭 VPN 的访问结果核对效果，不能用 30Mbps 峰值或实例运行状态代替用户体验验收。

## 运行与安全边界

- 后端继续使用现有非 root 镜像、单个进程、固定版本模型和有限缓存。
- PostgreSQL 使用独立数据库和 `insong` schema、持久卷和独立应用账户。数据库与后端端口仅在本机或专用容器网络可达。
- 保留生产环境的数据库 `verify-full` 验证。为本机 PostgreSQL 配置内部 CA 和匹配主机名的服务证书，不将生产设置降为明文连接。
- Nginx 提供 SPA 深链接回退和同源 API 转发。版本资源保持 immutable；身份、记录、照片响应保持 `no-store`。上传与搜索超时按现有接口规则处理。
- 域名使用有效 HTTPS 证书，保留 Secure、HttpOnly、SameSite=Lax Cookie。初始证书可通过 DNS 验证提前签发，切换后配置自动续期。
- 常规公网服务仅开放 HTTPS 和证书签发需要的 HTTP；SSH 使用密钥。临时管理公钥与 GitHub 发布公钥分开，发布账户限制为这个项目的上传和发布命令。
- 私钥、数据库连接串、内部 CA 私钥与备份不进入 Git、前端构建或工具输出。凭据由用户在明确的目标内私下填写；处理期间暂停其他网页操作。
- 不修改其他项目，例如 `spoken`，不导入本机 SQLite 私人数据。

## 数据迁移

1. 核对 Supabase 源项目和 `insong` schema；仅处理这个项目的数据。
2. 新服务器先完成服务准备和临时环境检查，保留原站点提供服务。
3. 最终导出前对原后端启用明确的写入暂停，返回可重试的维护提示，避免切换期间出现两边写入；读取尽量保持可用。
4. 生成受保护的 PostgreSQL 备份，恢复到新服务器的候选数据库，保留原编号、会话、照片字节、场次快照和序列。
5. 比较表行数、关键关系与照片内容哈希，验证备份可恢复。验证日志仅输出检查结果和数量。
6. 新站验证通过后才切换域名。失败时恢复原站读写和原 DNS；新的业务写入发生后需先核对数据，再回滚。

旧服务和源数据库作为切换恢复依据保留，删除它们需另行授权。浏览器草稿继续留在同一域名的本地存储中，不进入数据库迁移。

## 自动发布

- 源 `lxy` 先推送，再将同一个提交推至个人仓库 `main`。
- 只有部署仓库的 `main` 提交通过全部 CI，才触发服务器发布；PR 与源仓库不能调用生产发布。
- CI 产物标记完整提交 SHA；上传到新版本目录后校验内容。服务器预热新后端、验证数据库连接与健康状态，再切换前端和 API。
- 发布串行执行；失败保留当前健康版本。保留必要历史版本和静态资源，以支持回滚及已打开页面的延迟加载。
- 生产数据库不随代码发布重建。部署密钥不提供普通交互式管理权限。

## 验收

- 原有前后端、原生 PostgreSQL、真实 E5 和图片处理检查继续通过。
- 登录、私密多图、公开及撤回、创建／编辑／删除、场次关联和收藏在正式 HTTPS 域名正常工作。
- 备份恢复与重启后数据保留；匿名私密照片读取被拒绝。
- 一次个人仓库 `main` 提交实际触发自动发布，并核对服务器版本 SHA。
- 手机尺寸下无横向溢出，深链接与刷新正常，首页和共鸣图片可用。
- 持有人关闭 VPN 用手机检查实际加载速度；记录未测项，不承诺所有运营商或所有时段的网络表现。
- 仅在最终交付验证后清理本次临时脚本、测试账号、测试照片和工作副本；保留必要部署文件、最终证据和迁移恢复备份。
